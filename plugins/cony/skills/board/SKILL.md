# cony 보드 뷰어

`.cony/`를 감시하다가 파일이 바뀌면 브라우저에 바로 반영하는 로컬 서버를 띄운다. 리드는 지금처럼 `board.md`만 갱신하면 된다.

## 절차

1. 프로젝트에 `.cony/`가 있는지 확인한다. 없으면 "진행 중인 cony 작업이 없습니다"라고 알리고 끝낸다.
2. 이 스킬 디렉토리의 `server.mjs`를 프로젝트 루트에서 **백그라운드로** 실행한다.

   ```bash
   node "{이 스킬 디렉토리}/server.mjs"
   ```

   - 출력의 `cony board: http://localhost:{포트}` 에서 주소를 얻는다. 기본 포트는 4747이고, 사용 중이면 다음 포트를 쓴다.
   - 같은 프로젝트의 보드가 이미 떠 있으면 `(이미 실행 중)`과 함께 그 주소를 출력하고 끝난다. 그 주소를 그대로 쓴다.
3. 브라우저로 연다. 데스크톱 앱의 브라우저 패널 도구가 있으면 그걸로 열고, 없으면 macOS에서는 `open {주소}`로 연다.
4. 사용자에게 주소를 알려준다.

## 참고

- 서버는 `127.0.0.1`에만 열린다. 다른 기기(폰)에서는 볼 수 없다. 폰에서는 Remote Control과 `/cony:status`를 쓴다.
- 마크다운 렌더러를 CDN에서 받기 때문에 인터넷이 끊기면 원문 텍스트로 보인다.
- 서버를 끄려면 백그라운드 작업을 종료한다.
